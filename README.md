# TFG - Aplicación web para la recomendación de actividades que tengan un impacto positivo en el estado emocional

## Instalación

1. Clonar el repositorio
2. Instalar dependencias: npm install
3. Configurar la base de datos con el archivo SQL incluido
4. Ejecutar: npm start
